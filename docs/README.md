# Документация по проектной (учебной) практике

## Цель практики
Закрепление навыков работы с системами контроля версий, документирования проектов, создания статических веб-сайтов и разработки программного обеспечения.

## Задачи
1. Настройка Git-репозитория и освоение базовых команд
2. Написание документации в формате Markdown
3. Создание статического веб-сайта
4. Реализация вариативной части (Shell)
5. Подготовка итогового отчёта

## Ход выполнения

### Этап 1: Настройка Git (5 часов)
- Создан форк репозитория `mospol/practice-2025-1`
- Освоены команды: clone, commit, push, branch, merge
- Регулярно фиксировались изменения с осмысленными сообщениями

### Этап 2: Markdown-документация (5 часов)
- Изучен синтаксис Markdown
- Оформлены: README.md, документация, журнал прогресса

### Этап 3: Статический сайт (14 часов)
- Создан сайт на HTML + CSS
- Страницы: главная, о проекте, участники, журнал, ресурсы
- Добавлены графические материалы

### Этап 4: Взаимодействие с партнёром (8 часов)
- Проведена онлайн-встреча с куратором
- Составлен отчёт

### Этап 5: Вариативная часть — Shell (32 часа)
- Разработана собственная командная оболочка на Python
- Реализованы встроенные команды: cd, exit, help
- Написано техническое руководство

## Выводы
В ходе практики были получены навыки работы с Git, Markdown, HTML/CSS, а также углублены знания Python.
